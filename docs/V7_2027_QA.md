## 7. 상담 경로의 실제 작동 방식

1. **신청서**: 페이지의 "상담 신청서 미리 채우기"에서 관심 상품과 지원 예정 사업을 고르면 Google Forms 링크에 해당 값이 미리 입력됩니다. 실제 접수는 방문자가 Google Forms에서 "제출"을 눌러야 이루어지며, 페이지에 그 사실을 적어두었습니다. 이 페이지는 아무것도 저장·전송하지 않습니다.
   - 폼: "WeThru 무료 상담 신청", 응답 수신 중, 개인정보 수집·이용 동의 필수 문항 있음 (2026-10-11 확인)
   - 미리 채우기 검증: 헤드리스 브라우저로 링크를 열어 "사업계획서 전체 작성", "IR Deck · 발표자료"가 체크되고 2페이지 메모 문항에 값이 들어간 것을 확인. **테스트 응답은 제출하지 않았습니다.**
2. **카카오톡**: `https://pf.kakao.com/_wRVBX/chat` — 채널명 "WeThru 위쓰루 공식채널", 모바일에서 "카카오톡으로 채팅을 시작합니다" 화면 확인. 기존 사이트는 `/friend`(채널 추가) 링크였음.
3. **이메일**: ceo@nitual.com (mailto)
4. **전환 분석**: 분석 도구는 설치되어 있지 않습니다. 버튼 클릭 시 `window.dataLayer`가 있을 때만 `wethru_click` 이벤트를 넣도록 연결만 해두었고, 현재는 아무 데이터도 수집되지 않습니다.

## 9. 대표 확인이 필요한 항목

1. **"풀 작성" 상품의 이름과 범위** — 2026 예비창업패키지 공고는 대리 작성·제출을 처벌 대상으로 안내합니다. V7은 "전체 구성 지원"으로 표시하고 "최종 내용 확정과 제출은 대표님이 직접"이라고 썼습니다. 실제 계약 방식과 맞는지, 필요하면 법률 검토를 받아주세요.
2. FAQ "제출을 대행하지 않습니다" — 실제 운영 원칙과 맞는지.
3. 상품별 대상·범위·준비 자료·결과물 문구 — 기존 상품명에서 풀어 쓴 초안입니다.
4. 표시 가격의 부가세 포함 여부.
5. 사례 고객사명(ZOLV, GYMPT, 애스크미, 볼트앤너트, N15파트너스) 공개 동의 — 기존 운영 사이트에 이미 공개되어 있던 이름입니다. 확대 보기에서는 ZOLV 발표자료 18장의 인물 사진이 작게 보입니다.
6. 사례 분량은 썸네일 이미지에서 센 값입니다(이미지가 잘린 경우 "이상"으로 표기).
7. Google Form 선택지 "사업계획서 전체 작성"과 안내문 "1영업일 이내" 문구 — 사이트 문구와 맞출지.
8. `www.wethru.com`은 DNS 응답이 없고 HTTPS 인증서도 `wethru.com`만 포함합니다.

- `main`에 병합하면 GitHub Pages가 `index.html`을 V7로 교체합니다. 기존 앵커(`#problem`, `#services`, `#portfolio`, `#comparison`, `#testimonials`, `#final-cta`)는 사라져 외부에서 그 주소로 오면 페이지 맨 위가 열립니다.
- 새 폴더 `css/ js/ content/ tools/ assets/{brand,fonts,work,og}/`와 `robots.txt`, `sitemap.xml`이 공개됩니다.
- **`docs/`도 공개됩니다.** Pages가 Jekyll(legacy) 빌드라 이 문서가 `wethru.com/docs/V7_2027_QA.html`로 열릴 수 있습니다. 병합 전에 `docs/`를 빼거나 별도 처리 여부를 정해주세요.
- 외부 의존: Google Fonts(Noto Serif KR). 나머지는 모두 저장소 내부 파일.
- `CNAME`과 Pages 설정은 바꾸지 않았습니다. 사용하지 않게 된 기존 이미지는 지우지 않았습니다.

## 11. 수정 방법

1. `content/site.mjs`에서 문구·가격·링크를 고칩니다.
2. `node tools/build.mjs`를 실행합니다(`index.html`, `sitemap.xml` 재생성, CSS/JS 캐시 버전 자동 갱신).
3. 로컬 서버로 확인한 뒤 커밋합니다.
